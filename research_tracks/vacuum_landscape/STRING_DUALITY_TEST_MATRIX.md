# UBT–string-theory duality falsification checklist

**No established duality.** Compare one identified UBT physical sector with one identified string theory model; do not compare slogans.

| Gate | Required mathematical object | Current UBT status |
|---|---|---|
| Classical dynamics | Unique functional, stationary points, boundary conditions | Fundamental action family not finalized |
| Degrees of freedom | First-/second-class constraints and reduced phase space | Open |
| Graviton/string spectrum | Massless spin-2 pole, massive state tower and healthy residues | Open |
| Coupling map | Moduli, gauge/string coupling relation, scales | Open |
| Quantum duality | Observable/operator map, partition functions and controlled quantum regime | Open |
| Global sectors | Holonomies, fluxes, branes/topological charges and quotient | Proposed test, not counted |
| Anomalies | Matching gauge/gravitational anomalies under proposed map | Open |
| Prediction | Nontrivial quantitative match beyond postulated gravity | Open |

The common number *ten real dimensions* is not an equivalence invariant. UBT's complexified field/time bookkeeping cannot by itself be identified with ten target-space coordinates of a superstring. String compactification moduli are solutions/parameters subject to dynamics, not merely choices of representation of Theta.

**Hard stopping criterion:** if no unitary physical Hilbert space exists, or no graviton pole is present in the claimed shared sector, exact equivalence to a specified string model with such states fails. Conversely a single matching low-energy effective sector does not prove full duality.
