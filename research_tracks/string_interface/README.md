# UBT / string-theory interface — deferred research track

**Status: PARKED / NOT AN AXIOM / NOT A RESULT.** The immediate priority remains the single-Theta action, source variation, and full physical constraint algebra.

## Hypotheses worth testing later
1. **Torsion / Kalb–Ramond interface.** Given the UBT *axial* torsion 3-form H_T on a selected on-shell background, test dH_T=0. Only a locally closed H_T admits H_T=dB by the Poincare lemma on a contractible patch; global B requires additional cohomology conditions. A frame bivector Sigma is not automatically a Kalb–Ramond potential. Identify the gauge transformations B->B+dLambda_1 and whether the single-Theta sector realizes them.
2. **Dilaton comparison.** Ask whether an already derived gauge-invariant Theta scalar has an effective e^{-2Phi} R coupling and healthy independent kinetic data. No standalone Phi field is introduced.
3. **Modular consistency.** Distinguish complex UBT time tau=t+i psi from modular worldsheet tau_ws; establish a valid partition function and modular group action before comparing theta functions or spectra.
4. **Spectrum test.** Compare independent physical reduced degrees of freedom, anomalies, and unitarity. Numerical resemblance of dimensions or theta functions is not evidence of equivalence.

**Gates:** exact map of variables, matching gauge identities and variations, same reduced spectrum, at least one falsifiable distinction. No additions to the canonical action, GR closure, or dimension axioms until independently derived.

**Resume only after:** the source-coupled full UBT action and presymplectic/Dirac constraint programme attain a reviewable status.
