# Split-jet auxiliary sector does not generate a colour current-current channel

**Status:** exact action-level no-go for reusing the existing GR split-jet
auxiliary constraint as the emergent SU(3) vector mechanism.

## 1. Existing auxiliary action

On a non-null Lorentz-real patch the canonical action track contains
\[
C_\mu{}^a
=
\mathring D_\mu X^a
+
K^{J\,a}{}_{\mu b}X^b
+
w_\mu X^a
-
\sqrt{\mathcal N_0}e_\mu{}^a
\]
and
\[
\boxed{
S_{\rm aux}
=
\int d^4x\sqrt{-g}\,
\lambda_a{}^\mu C_\mu{}^a.
}
\]

The fields \(K^J\) and \(w\) are algebraic jet variables and
\(\lambda_a{}^\mu\) is a Lagrange multiplier.

## 2. Exact variation

Variation with respect to \(K^J_{\mu ab}=-K^J_{\mu ba}\) gives
\[
\lambda^{\mu[a}X^{b]}=0.
\]

For nonzero non-null \(X\), this implies for each \(\mu\)
\[
\lambda^{\mu a}=\alpha^\mu X^a
\]
for some scalar \(\alpha^\mu\).

Variation with respect to \(w_\mu\) gives
\[
\lambda_a{}^\mu X^a=0.
\]

Therefore
\[
\alpha^\mu X^2=0.
\]

On the non-null patch \(X^2\ne0\),
\[
\boxed{\alpha^\mu=0}
\]
and hence
\[
\boxed{\lambda_a{}^\mu=0.}
\]

Variation with respect to \(\lambda\) independently enforces
\[
\boxed{C_\mu{}^a=0.}
\]

Thus the auxiliary sector is a pure algebraic right-inverse constraint.

## 3. No current-current interaction is generated

A Hubbard--Stratonovich/current-current mechanism requires schematically
\[
\frac{M^2}{2}B_\mu B^\mu+B_\mu J^\mu
\]
or an equivalent quadratic kernel whose elimination yields
\[
-\frac{1}{2M^2}J_\mu J^\mu.
\]

The existing split-jet action contains no such quadratic auxiliary kernel.

Instead it is linear in the multiplier:
\[
S_{\rm aux}\sim\lambda C.
\]

Eliminating the algebraic variables imposes \(C=0\) and \(\lambda=0\); it does
not produce
\[
J_\mu^aJ^{a\mu}
\]
or any other vector-channel four-field interaction.

In the path integral, integration over \(\lambda\) produces a delta functional
\[
\delta[C],
\]
not a Gaussian vector propagator.

## 4. No independent vector pole from this sector

Because \(K^J,w,\lambda\) are nonpropagating constraint variables and their
on-shell source vanishes, the present auxiliary sector does not contain a
quadratic vector inverse propagator that could be dressed into an independent
massless colour pole.

It can enforce the generic-GR jet right inverse, but it cannot simultaneously
serve as the missing strong/composite SU(3) mechanism.

Therefore
\[
\boxed{
\text{existing split-jet auxiliary GR branch}
\not\Rightarrow
\text{colour current-current interaction}
}
\]
and
\[
\boxed{
\text{existing }K^J,w,\lambda
\text{ cannot be reinterpreted as emergent gluons}.
}
\]

## 5. Consequence

Any Axiom-A-compatible composite-gluon route must introduce a **different exact
collective transformation or interaction channel** derived from the same
Theta action.

Possibilities include:
- a genuinely nonlocal/spectral collective variable;
- a derived adjoint bilinear with a strong Bethe--Salpeter kernel;
- a critical current-current interaction generated by integrating a different
  nonpropagating sector;
- or a revision of the microscopic action.

Such a mechanism must still satisfy the composite pole criterion and must not
be inserted merely to obtain QCD.
