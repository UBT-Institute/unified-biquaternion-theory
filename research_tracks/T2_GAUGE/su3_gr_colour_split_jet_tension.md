# GR–colour tension: the split-jet dilation is required for rank four

**Status:** exact local no-go on the phase-normalized Lorentz-real vacuum
branch.  It identifies the specific split-jet term that conflicts with exact
constant-norm SU(1,3)-enhanced transport.

## 1. Existing split-jet right inverse

For a non-null Lorentz-real representative \(X^a\), the existing exact
split-jet construction is
\[
\widehat D_\mu X^a
=
\mathring D_\mu X^a
+
K^{J\,a}{}_{\mu b}X^b
+
w_\mu X^a
=
s e_\mu{}^a,
\qquad
s=\sqrt{\mathcal N_0}.
\]

The tensor \(K^J_{\mu ab}\) is antisymmetric in its Lorentz indices, while
\(w_\mu\) is the relative central/dilation one-form.

The latter is
\[
w_\mu
=
\frac{X_a(s e_\mu{}^a-\mathring D_\mu X^a)}{X^2}.
\]

## 2. Norm evolution

Because \(K^J\) is Lorentz-antisymmetric,
\[
X_aK^{J\,a}{}_{\mu b}X^b=0.
\]

Metric compatibility of the Levi--Civita derivative gives
\[
X_a\mathring D_\mu X^a
=
\frac12\partial_\mu X^2.
\]

Therefore
\[
\boxed{
X_a\widehat D_\mu X^a
=
\frac12\partial_\mu X^2+w_\mu X^2.
}
\]

A jet connection preserves the Lorentz norm in the ordinary compatible sense
only when
\[
\boxed{w_\mu=0.}
\]

This agrees with the original split-jet note: \(w_\mu\) is precisely the
piece that is not required to preserve the Lorentz norm under jet transport.

## 3. Constant-norm vacuum plus norm-preserving transport

On the phase-normalized Lorentz-real representative of the timelike potential
minimum, the enhanced \(\lambda_2=0\) branch has
\[
X^2=\text{constant}\ne0.
\]

If in addition the jet transport preserves this norm, then \(w_\mu=0\) and
\[
X_a\widehat D_\mu X^a=0.
\]

Using the right-inverse equation,
\[
\widehat D_\mu X^a=s e_\mu{}^a,
\]
gives
\[
\boxed{
X_a e_\mu{}^a=0
\qquad
\text{for every }\mu.
}
\]

Thus all four tetrad columns lie in the Lorentz-orthogonal complement
\[
X^\perp\subset\mathbb R^{1,3}.
\]

For non-null \(X\),
\[
\dim_{\mathbb R}X^\perp=3.
\]

Consequently
\[
\boxed{
\operatorname{rank}(e_\mu{}^a)\le3.
}
\]

A nondegenerate four-dimensional tetrad is impossible.

## 4. Exact architecture conflict

Within this branch, the following four requirements cannot all hold:

1. the field sits on the phase-normalized constant-norm timelike vacuum;
2. the defining jet connection preserves that norm / stays in the
   corresponding \(SU(1,3)\)-type orbit structure;
3. the tetrad is generated by the same single field through
   \(\widehat D_\mu X=s e_\mu\);
4. the tetrad has rank four.

Therefore
\[
\boxed{
\text{exact enhanced colour orbit}
+
\text{norm-preserving split jet}
+
\text{canonical one-field tetrad}
\not\Rightarrow
\text{4D nondegenerate GR}.
}
\]

## 5. Why the existing split-jet construction evades the rank no-go

The generic-GR right inverse keeps
\[
w_\mu
=
\frac{X\cdot(s e_\mu-\mathring D_\mu X)}{X^2}
\]
instead of setting it to zero.

That term supplies exactly the component of the tetrad parallel to \(X\).
It is therefore what allows four independent tetrad directions.

But it is a local dilation of \(X\), not a norm-preserving Lorentz/SU(1,3)
transport.

So the same term that restores generic four-dimensional tetrad
representability breaks the exact constant-norm enhanced colour geometry at
the defining-jet level.

## 6. Scope

This theorem applies to the phase-normalized Lorentz-real representative used
by the current pointwise vacuum and split-jet constructions.

It does not exclude more elaborate possibilities in which:
- the full complex Theta has additional components while its Lorentz-real
  projection changes norm;
- colour is carried by a separate composite bundle not locked to the same
  norm as the tetrad-generating representative;
- the physical vacuum moves slightly off the exact pointwise minimum;
- the colour symmetry is only infrared/emergent rather than exact in the
  tetrad-generating UV variables.

Those are now the only honest escape routes inside the one-field programme.

## 7. Consequence for action selection

The conflict makes the next design criterion precise.

A successful single-action completion must separate, dynamically rather than
by hand,

- the degree of freedom that supplies the fourth tetrad direction / dilation,
  from
- the rank-three colour bundle whose internal frame redundancy is to remain
  \(SU(3)\).

If the same constant-norm representative is required to do both jobs with a
norm-preserving connection, rank four is impossible.
