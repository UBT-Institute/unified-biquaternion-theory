# Adjoint current vertex in the Stiefel HLS formulation

**Status:** exact small-field expansion around the reference timelike frame.

## 1. Coset triplet coordinate

Use the reference frame
\[
n_0=e_0,
\qquad
Z_0=
\begin{pmatrix}
0\\
I_3
\end{pmatrix}.
\]

A pure noncompact coset fluctuation is generated by
\[
\pi(\beta)
=
\begin{pmatrix}
0&\beta^\dagger\\
\beta&0
\end{pmatrix},
\qquad
\beta\in\mathbb C^3.
\]

It obeys
\[
\pi^\dagger G+G\pi=0.
\]

With
\[
g=e^\pi,
\qquad
Z=gZ_0,
\]
the constrained Stiefel frame expands as
\[
\boxed{
Z=
\begin{pmatrix}
\beta^\dagger\\
I_3+\frac12\beta\beta^\dagger
\end{pmatrix}
+O(\beta^3).
}
\]

This automatically satisfies
\[
Z^\dagger GZ=-I_3+O(\beta^4).
\]

## 2. Frame current

Define
\[
C_\mu
=
Z^\dagger G\partial_\mu Z.
\]

Substituting the expansion gives
\[
\boxed{
C_\mu
=
\frac12
\left[
\beta\,\partial_\mu\beta^\dagger
-
(\partial_\mu\beta)\beta^\dagger
\right]
+O(\beta^3).
}
\]

This is anti-Hermitian, as required by the Stiefel constraint.

Its traceless part is
\[
\boxed{
C_{\mu,0}
=
\frac12
\left[
\beta\,\partial_\mu\beta^\dagger
-
(\partial_\mu\beta)\beta^\dagger
\right]_0
+O(\beta^3)
\in su(3).
}
\]

Thus the first nonzero hidden-local \(SU(3)\) current is bilinear in the
physical complex triplet fluctuation.

## 3. Gell-Mann components

With Hermitian generators
\[
T^a=\lambda^a/2,
\qquad
\operatorname{tr}(T^aT^b)=\frac12\delta^{ab},
\]
write
\[
C_{\mu,0}=iJ_\mu^aT^a.
\]

Then, up to the declared sign convention,
\[
\boxed{
J_\mu^a
\propto
i\,
\beta^\dagger T^a
\stackrel{\leftrightarrow}{\partial_\mu}
\beta.
}
\]

So the exact Stiefel expansion reproduces the standard adjoint bilinear current
used in the weak-current benchmark.

This current is no longer inserted by hand; it is the traceless vertical frame
current of the derived rank-three colour bundle.

## 4. Coupling to the auxiliary HLS connection

The redundant vertical term is
\[
\mathcal L_V
=
-c_V\,
\operatorname{tr}
(B_\mu-C_{\mu,0})^2.
\]

Expanding,
\[
\mathcal L_V
=
-c_V\operatorname{tr}B_\mu B^\mu
+
2c_V\operatorname{tr}(B_\mu C_0^\mu)
-
c_V\operatorname{tr}C_{\mu,0}C_0^\mu.
\]

Because
\[
C_{\mu,0}=O(\beta\,\partial\beta),
\]
the second term is the cubic interaction
\[
\boxed{
B\,\beta\,\partial\beta
}
\]
that can generate a transverse \(B\)-field vacuum polarization.

The final term is a derivative quartic interaction of the triplet.

## 5. Fixed-frame phase remains massive

At
\[
\beta=0,
\qquad
C_{\mu,0}=0,
\]
the vertical term contains
\[
-c_V\operatorname{tr}B_\mu B^\mu.
\]

Therefore a semiclassical expansion around the fixed frame has a nonzero HLS
mass coefficient if \(c_V>0\).

A one-loop polarization generated by the cubic current vertex does not by
itself remove this zero-momentum term.

Thus the weak fixed-frame phase is vector-meson-like, not unbroken QCD colour.

## 6. Why the quantum phase question remains open

The exact HLS rewrite permits a different quantum phase because the frame
itself is a redundant constrained variable.

Known Grassmannian HLS models can have a gauge-fixed symmetric/unbroken phase
in which the auxiliary vector acquires a kinetic term while its renormalized
mass vanishes.

For UBT this cannot be inferred from the local expansion above.

One must solve the finite \(4\times3\), noncompact constrained theory and
determine the full renormalized inverse vector propagator
\[
\Gamma^{(2)\,ab}_{\mu\nu}(p).
\]

The decisive conditions are
\[
\Gamma_T^{ab}(p)
=
\delta^{ab}
\left[
m_{B,\rm ren}^2
+
Z_B p^2
+O(p^4)
\right],
\]
with
\[
\boxed{
m_{B,\rm ren}^2=0,
\qquad
Z_B>0
}
\]
in a candidate unbroken colour phase.

## 7. Practical next step

The exact current vertex makes a finite functional-RG or Schwinger--Dyson
truncation well defined.

A minimal truncation should evolve:
- the triplet/singlet sigma-model metric;
- \(c_V\);
- the constraint multiplier sector;
- the generated \(Z_B\);
- the HLS vector mass coefficient;
- the leading gauge-consistent cubic/quartic vertices.

The flow must preserve the local \(SU(3)\) Ward/Slavnov--Taylor identities.
